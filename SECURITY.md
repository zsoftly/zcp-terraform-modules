# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in these modules, please do **not**
open a public GitHub issue. Report it privately by email to
[security@zsoftly.ca](mailto:security@zsoftly.ca) or through
[GitHub Security Advisories](https://github.com/zsoftly/zpcp/security/advisories/new).

We acknowledge receipt within 3 business days and work with you to resolve the
issue promptly.

## Scope

This policy covers the Terraform module source code in this repository. Report
security issues in the ZSoftly Apache CloudStack platform itself to
[security@zsoftly.ca](mailto:security@zsoftly.ca).

## Supported Versions

We provide fixes for the current `main` branch. Pin a specific Git ref or tag in
production.
